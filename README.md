# City2049 Reference

City2049 的未来文化参考库。它从书、电影、剧集与游戏中收集关于未来城市、人工智能、气候、能源、治理与人的日常的想象，并把这些作品连接到可以继续建模和验证的 City2049 项目。

[在线访问](https://marsguo2049.github.io/city2049-reference/)

## 当前内容

- 24 个书、电影、剧集与游戏条目
- 8 个未来命题与跨媒介筛选
- 从文化作品到 OR 项目的参考桥梁
- 搜索、随机探索与单条目详情

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm ci
npm run dev
```

## 说明

文化作品在这里用于发现问题、形成假设与扩展情景，而不是代替论文、真实数据或实验。部分尚无简体中文版的作品采用暂译，并保留英文原名。
